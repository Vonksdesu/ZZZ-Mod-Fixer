# ZZZ-Mod-Fixer (Community Update)

This is a Python-based tool designed to update and fix character skin mod hash IBs for the game **Zenless Zone Zero (ZZZ)** to ensure compatibility with the latest versions of the game.

---

## Revamps 2.0.0

This time, I’ve made some changes to the ZZZ Mod Fixer tool.

### What's new

* **Integrated GUI**: This time, I’ve updated the ZZZ Mod Fixer by integrating an application-based UI, whereas previously it relied solely on a CLI.
* **Backup Options**: In this update, I have also added a folder backup option for users. This allows them to choose whether to perform changes with or without a backup—a choice that was not available in the previous CLI version.
* **Adding other tools besides the ZZZ Mod Fixer tool**: In this update, In this update, I have also added two tools alongside the ZZZ Mod Fixer. These additional tools originate directly from [Satan1c](https://github.com/Satan1c/ZZMI_tools/wiki/Jane-2.5-fix) repository and have been ported to Python by me. Here are the tools:
  * **Jane Remapper**
  * **Dialyn Remapper**
* **Basic Guide**: I have also added a basic guide feature here.
